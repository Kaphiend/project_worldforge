# Data-table modding notes

These files explain the JSON table with the same name. They are intentionally
outside the JSON because JSON does not support comments. For the full workflow,
loader behavior, and Python source map, read [`../modding/README.md`](../../modding/README.md).

- [`classes.md`](classes.md): class skills, starting gear, and descriptive progression.
- [`progression.md`](progression.md): XP ledgers, class pool curves, and rest rules.
- [`races.md`](races.md): race traits, subraces, selectable options, and half-breed.
- [`subclasses.md`](subclasses.md): class links and milestone entries.
- [`equipment.md`](equipment.md): item templates, slots, tags, weapon math, and consumables.
- [`item_attributes.md`](item_attributes.md): rollable gear attributes, item-level filters, and effects.
- [`mob_generation.md`](mob_generation.md): mob class priorities, elite rolls, item rarity, and affix counts.
- [`spells.md`](spells.md): targets, range, resolution, and effect records.
- [`abilities.md`](abilities.md): class abilities and action costs.
- [`conditions.md`](conditions.md): status duration and supported condition primitives.
- [`npcs.md`](npcs.md): NPC actor fields, perception tiers, and AI controller choice.
- [`arenas.md`](arenas.md): bounds, colors, obstacles, and decorations.
- [`scenarios.md`](scenarios.md): player positions, enemy references, objectives, and victory.
- [`demo_slice.md`](demo_slice.md): how the included example mod fits together.
